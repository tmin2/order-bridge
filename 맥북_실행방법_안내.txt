========================================================
  OrderBridge 발주서 자동 변환 시스템 - 맥북(macOS) 사용 안내
========================================================

맥북(MacBook, iMac, Mac mini)에서 사용하시는 방법 안내입니다.

1. 준비 사항
   • 맥북에 Python 3가 설치되어 있어야 합니다.
     (터미널에서 'python3 --version' 입력 시 버전이 나오면 이미 설치된 상태입니다.)
     미설치 시: https://www.python.org/downloads/ 에서 macOS용 설치 파일 다운로드

2. 실행 방법 (더블 클릭)
   • 폴더 내의 [01_대시보드_실행_Mac.command] 파일을 더블 클릭합니다.
   • 최초 1회 실행 시 필요한 라이브러리를 자동으로 다운로드하고 세팅한 뒤 브라우저가 자동으로 열립니다.
   • 두 번째 실행부터는 2초 만에 즉시 실행됩니다.

   ※ [참고: 보안 경고가 뜰 경우]
   macOS 보안 정책으로 인해 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면:
   1) 파일 우클릭(또는 Control + 클릭) ➔ [열기] 선택
   2) 팝업 창에서 [열기] 버튼을 누르면 다음부터는 더블 클릭으로 바로 열립니다.

   ※ [참고: 실행 권한이 없다고 뜰 경우]
   터미널(Terminal)을 열고 해당 폴더로 이동한 뒤 아래 명령어를 한 번 입력해주세요:
   chmod +x *.command

3. 종료 방법
   • 터미널 창에서 [Ctrl + C]를 누르거나 창을 닫으셔도 되고,
   • [99_대시보드_종료_Mac.command] 파일을 더블 클릭하시면 바로 종료됩니다.
