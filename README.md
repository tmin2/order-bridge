# 📦 공동구매 발주서 자동 변환 & 정산 대시보드 (OrderBridge)

공동구매 SNS 마켓 벤더사 실무자를 위한 웹 대시보드 솔루션입니다.  
셀러별 발주서를 브랜드사 표준 양식으로 즉시 변환하고, 선착순/금액 이벤트 조건 판정 및 일자별 수량/배송비 정산표를 3초 만에 생성합니다.

---

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 배치 파일로 원클릭 실행 (추천)
`run_dashboard.bat` 파일을 더블 클릭하면 자동으로 웹 브라우저가 열리고 대시보드가 실행됩니다.

### 방법 2. 터미널 / 파워쉘에서 실행
```bash
cd C:\Users\TMIN\.gemini\antigravity\scratch\order_bridge
streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 접속됩니다.

## 🛠️ 주요 기능

1. **셀러 발주서 스마트 자동 매핑**
   - 셀러마다 제각각인 컬럼명(받는분, 수령인, 주문시간, 결제일시 등)을 자동 인식하여 정규화
   - 셀러별 상품명 표기(`[공구특가] 수분크림 50ml`, `아쿠아 수분크림(본품)`)를 브랜드사 표준 상품명으로 자동 치환

2. **이벤트 조건부 자동 라벨링 & 사은품 처리**
   - **선착순 이벤트:** 초 단위 주문시간 기준 자동 정렬 후 상위 N명 판별 (비고란 색인 또는 사은품 출고용 별도 행 자동 추가)
   - **구매금액 조건:** 주문건별 합산 결제금액 N만원 이상 구매자 사은품 자동 판정
   - **특정 품목 구매자:** 특정 세트/제품 구매 시 사은품 라벨링

3. **배송비 & 제주/도서산간 자동 판별**
   - 주소 및 우편번호(63000번대 등)를 분석하여 제주/도서산간 지역 자동 분류
   - 무료배송 기준 금액(예: 5만원 이상)에 따른 유/무료 배송비 및 제주 추가배송비 자동 계산

4. **1클릭 3종 결과 통합 엑셀 다운로드**
   - 하나의 엑셀 파일(`.xlsx`)에 아래 4개 시트가 서식(헤더 색상, 너비 조정, 이벤트 하이라이트)과 함께 깔끔하게 저장됩니다:
     1. **`브랜드사_발주서`**: 브랜드사 제출 양식 (사은품 행 및 이벤트 색인 적용)
     2. **`일자별_품목수량표`**: 일자별/품목별 판매 수량 피벗 요약표
     3. **`일자별_배송정산표`**: 일자별 주문건수, 유/무료 배송, 제주 추가비 정산표
     4. **`셀러통합_판매DB`**: 전 셀러의 주문 내역을 표준 규격으로 누적 적재할 수 있는 마스터 Raw Data
